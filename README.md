# Oluwaseun Ogunkoya — Portfolio

Creative-tech portfolio built with HTML, CSS and vanilla JavaScript.

## Preview
Open `index.html` in a browser. The portrait is stored at `assets/portrait.jpg`.

## Publish using GitHub Pages
1. Create a new public GitHub repository (for example `portfolio`).
2. Upload all files, preserving the `assets` folder.
3. In repository Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/(root)**.
4. Visit `https://zeem2x.github.io/portfolio/` once Pages reports deployment.

## Before publishing
- Review project descriptions and employment details for accuracy.
- Add direct project repository links once approved for public sharing.
- Add your resume PDF if you'd like a downloadable resume button.
- The font uses Google Fonts; system fonts are used as a fallback.
